Build a realistic working web application called:

"HTSI Early Warning System"

Full form:
Extreme Heatwave Early Warning + Human Thermal Stress Index

IMPORTANT:
This must NOT be a static mockup or fake dashboard.

The application must use REAL-TIME WEATHER DATA and calculate HTSI dynamically from that data.

==================================================
1. CORE PRODUCT
==================================================

Build a functional heat-risk monitoring dashboard.

The system should:

1. Detect the user's current location using browser geolocation.
2. Get latitude and longitude.
3. Fetch real-time weather data for that location.
4. Calculate HTSI dynamically using the real weather values.
5. Display the current weather and HTSI.
6. Display the thermal stress risk level.
7. Display hourly forecast-based HTSI for the next 24 hours.
8. Show the highest expected HTSI.
9. Show when the highest-risk period is expected.
10. Clearly indicate when data was last updated.
11. Allow the user to manually search/select a city.
12. Work for major Indian cities.
13. Never display fake hardcoded weather values when API data is available.

==================================================
2. WEATHER DATA SOURCE
==================================================

Use Open-Meteo as the default weather provider.

Open-Meteo forecast API:

https://api.open-meteo.com/v1/forecast

Use latitude and longitude dynamically.

Request these current variables:

temperature_2m
relative_humidity_2m
wind_speed_10m
surface_pressure
shortwave_radiation
weather_code
cloud_cover

Also request hourly values for:

temperature_2m
relative_humidity_2m
wind_speed_10m
surface_pressure
shortwave_radiation
weather_code

Use appropriate units:

temperature_unit=celsius
wind_speed_unit=ms
pressure_unit=hPa

Use timezone=auto.

The application must NOT use fake weather values.

==================================================
5. REAL-TIME HTSI CALCULATION
==================================================

Create a dedicated HTSI calculation module.

File/module:

htsi.ts

or

htsi.py

depending on the selected backend.

Input:

temperature_c
relative_humidity_pct
wind_speed_ms
solar_radiation_wm2

Return:

{
  "htsi": number,
  "risk_level": string,
  "risk_color": string,
  "description": string
}

IMPORTANT:

Do NOT invent random numbers.

Use the project's existing HTSI methodology if it already exists.

If an existing HTSI formula is not available, create a clearly documented baseline formula and mark it as:

"Prototype HTSI model"

Do not present an invented formula as an official medical or government heat index.

Keep all thresholds and weights centralized in one configuration file:

htsi_config

Example:

HTSI_THRESHOLDS
HTSI_WEIGHTS
NORMALIZATION_RANGES

Do not scatter magic numbers throughout the application.
